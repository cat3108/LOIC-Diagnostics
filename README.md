# LOIC Diagnostics

Aplicación Android de diagnóstico de red en modo seguro, con interfaz oscura y azul.

## Funciones
- Resolución DNS de un host.
- Comprobación individual de alcance/latencia.
- Prueba de una conexión TCP a un puerto especificado.

No incluye tráfico masivo, inundación UDP/TCP/HTTP ni funciones de denegación de servicio. Utiliza las pruebas únicamente en equipos y redes para los que tengas autorización.

## Compilación
GitHub Actions compila el APK de depuración automáticamente al hacer push. El archivo se publica como artefacto descargable en la ejecución del workflow.
